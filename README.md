# Backendbot

Backendbot es una API construida con FastAPI para monitoreo y control de procesos, con funcionalidades avanzadas de health checks, logs y métricas.

## Inicio Rápido
1. Haz doble click en `Start-BackendBot.bat` para iniciar el backend completo.
2. Haz doble click en `Open-Dashboard.bat` para abrir el dashboard en el navegador.

## Dashboard Frontend
- **index.html**: Dashboard simple con navegación a Pro y API Docs.
- **pro_dashboard.html**: Dashboard avanzado con gráficos en tiempo real y métricas.

## Características Frontend
- Navegación intuitiva entre dashboards.
- Gráficos interactivos con Chart.js.
- Diseño responsivo con Tailwind CSS.
- Enlaces directos a API Docs.

## Instalación
```bash
pip install -r requirements.txt
```

## Ejecución
- `Start-BackendBot.bat`: Inicia el backend completo.
- `Open-Dashboard.bat`: Abre el dashboard.
